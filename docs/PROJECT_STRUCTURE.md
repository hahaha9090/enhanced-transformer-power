# 项目结构说明

本文档用于约定仓库的目录职责，避免后续实验代码、模型产物和文档混杂。

## 顶层目录

- `src/`：核心训练、评估、模型定义与工具函数。
- `scripts/`：辅助脚本，例如环境检查、数据准备、结果整理。
- `docs/`：项目文档、设计说明、实验记录模板。
- `tests/`：测试代码。
- `data/`：数据集目录，不纳入 Git 管理。
- `models/`：训练中间产物，不纳入 Git 管理。
- `best_models/`：最佳模型导出目录，不纳入 Git 管理。
- `runs/`：TensorBoard 等运行日志，不纳入 Git 管理。
- `results/`：评估结果与导出文件，不纳入 Git 管理。

## 当前约定

- 保持现有 `python -m src.train` 和 `python -m src.benchmark` 入口不变。
- 新增的工具脚本统一放入 `scripts/`，避免继续在 `src/` 目录中堆放临时文件。
- 所有新增代码文件统一使用 UTF-8 编码。
- 所有新增代码中的注释统一使用中文。

## 后续建议

- 将训练超参数从代码内联配置提取到独立配置文件。
- 为 `src/` 增加更稳定的模块导入方式，避免依赖当前工作目录。
- 为训练与评估主流程补最小可运行测试。
